# WheelDesk
 In this project, I build a Platform for comparing car prices from different dealerships. I make use of:
 * <b>SQL</b> and <b>MySQL</b> database to store data from the app,
 * <b>Java</b> for the functionality of the app and
 * <b>JavaFX</b> as the GUI

The app features a secure login system
* Password hashing
* User Authentication
